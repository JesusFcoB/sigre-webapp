# Frontend Design Skill

This skill enforces modern web design aesthetics and best practices.

## Guidelines
1. **Mobile-First Approach**: Always design the UI starting from mobile viewports. Ensure buttons are large enough for touch targets (min 44px height).
2. **Contrast & Legibility**: Use high-contrast text and legible typography (e.g., sans-serif fonts, adequate line-height).
3. **Micro-interactions**: Incorporate subtle animations (hover states, active scaling, transitions) to make the UI feel alive.
4. **Color Hierarchy**: Use primary colors for primary actions, secondary colors for less important actions, and destructive colors (red) strictly for critical negative actions.
5. **Simplicity**: Avoid clutter. Use generous whitespace to separate visual components.
